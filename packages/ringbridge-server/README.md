# ringbridge-server

Ringbridge control plane: API, data model and durable workflows.

```sh
python -m ringbridge_server migrate
python -m ringbridge_server serve      # http://127.0.0.1:8088/docs
```

See [docs/control-plane.md](https://github.com/annmary-ann/ringbridge/blob/main/docs/control-plane.md).

Part of [Ringbridge](https://github.com/annmary-ann/ringbridge). Pre-alpha: APIs will change.
