# Security policy

Ringbridge handles phone numbers, call recordings, transcripts and third-party credentials, so security reports are taken seriously.

## Reporting a vulnerability

Please **do not open a public issue**. Use [GitHub private vulnerability reporting](https://github.com/annmary-ann/ringbridge/security/advisories/new). You will get an acknowledgement within 5 working days.

## Supported versions

Pre-1.0: only the latest release receives fixes.
