# Code of conduct

Ringbridge follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, welcome newcomers, give and accept constructive feedback, and focus on what is best for the community. Harassment, insults and personal attacks are not accepted in any project space.

To report unacceptable behaviour, use GitHub's [private vulnerability / report feature](https://github.com/annmary-ann/ringbridge/security) or contact the maintainer through their GitHub profile. Reports are handled confidentially.
